# Impact_of_Weather_on_Taxi_Service_Demand

## Project Description

This project focuses on analyzing the relationship between weather conditions and taxi service demand in New York City during the year 2024. The goal was to determine whether and how factors such as temperature, precipitation, wind, and rainy days influence the number of taxi rides.

### Data Preparation

To prepare the dataset, I merged 12 separate monthly NYC Green Taxi datasets into a single file and combined them with daily weather data. The dataset was further enriched with a custom "RainDay" category and a numeric month column to support visualization.

### Tools & Methods

I used Power BI and Python (pandas, seaborn, matplotlib) for data visualization and analysis. The analysis includes various types of charts and models:

- Bar charts  
- Line charts  
- Scatter plots  
- Correlation heatmaps  
- Pairplots  
- Linear regression models
